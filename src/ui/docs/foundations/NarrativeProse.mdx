# Narrative Prose

This is the surface where the story actually happens — the roleplay-scoped prose layer in
`theme.css`, rendered by `ChatMessage` for every Game Master turn. It is the clearest
expression of **"serif for story, sans for system":** the UI recedes, and the prose
glows in Spectral.

JSON segments carry narration, speech and fictional thoughts. Their bodies support bounded Markdown; formatting does not determine the speaker or segment kind.

## The roleplay vocabulary

- **Narrator segments** use muted italic prose so actions stay distinct from spoken words.
- **Speech segments** use brighter, medium-weight prose aligned with the narration. Group replies show roster identity; solo replies share the turn header. Quotation marks remain ordinary prose.
- **`*Action*`** and single-tilde actions use muted italics; double tildes remain deletion.
- **Thought segments** explicitly label fictional, unspoken text. **Bold stays emphasis**, with no generated parentheses.
- Roleplay body text uses the dedicated **Spectral** roleplay type token at a comfortable reading measure.

## Player vs. Game Master

The player's turn is an **ember candlelit bubble** in the UI sans; the Game Master's
turn is serif prose. The contrast is deliberate — *you* speak in the present, the world
answers in story.

## Markdown

Headings mark scene breaks; lists offer choices; blockquotes and inline `code` carry
emphasis and artifacts. All re-styled to the candlelit theme.

> Implementation: `ChatMessage` maps decoded segments to narration, attributed speech and labeled thought treatments. Its chat-only Markdown allowlist preserves lore marks and readable labels while preventing generated media/network elements. Inline code stays inline. Styles use existing Reverie tokens; shared assistant Markdown defaults are unchanged.
