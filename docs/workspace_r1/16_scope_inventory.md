## Intentionally unchanged account/application boundaries

Auth/OAuth, user language preferences, billing/subscriptions/Patreon, memberships/credits/quotas, notifications inbox policy, voice consent/quota accounting, user/system voice presets, admin voices/agents, LLM profiles/catalog/defaults/BYOK, and image profiles/catalog/defaults/BYOK keep their current boundaries.

The image-profile revision is relevant to schema compatibility, not a request for workspace-specific image profiles. Internal writer execution origin is workspace-local while its system profile remains project-owned. Generic administrative executions and content executions must be distinguished before restricting /llm/features/…/executions or receipts.

Worker/webhook handlers are trusted internal entry points, not anonymous workspace-selector endpoints. Reconstruct context from the retained job/execution, verify owner/workspace relationships, and admit only the finalization action associated with that record.
